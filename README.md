# Solana Security Lab 🛡️

An open-source educational project designed to help
Solana users understand wallet-drainer attacks and
protect their crypto assets.

## Features

- Phantom wallet connection
- SOL wallet inspection
- SPL token inspection
- Suspicious instruction detection
- Transaction analysis
- Educational attack simulations
- Security warnings

## Technology

- JavaScript
- Solana Web3.js
- Phantom Wallet
- Solana Devnet

## Safety

This project is for educational and defensive
security research.

It does not collect private keys, seed phrases,
or perform unauthorized transfers.
